できること

打つ、覚える、確かめる

ヒット・ステイ・ダブル・スプリット・サレンダー。各場面でどれが最善かを、卓の上で身につけます。

通常ゲーム

一手ごとに、最善手かどうかが分かる

ベット、配る、判断、精算。本物と同じ流れの卓で遊びながら、判定の枠がその手の正解を教えてくれます。

判定は「なし」「あり簡易版」「ありプロ版」から選択。ありプロ版は全部の手の期待値（%）も表示します。

ストラテジー表

いまの卓のルールに合わせた表

ハード・ソフト・ペアの 3 枚。ゲーム中もボタン 1 つで開けるので、迷ったらすぐ確かめられます。

1手ドリル・実力テスト

覚える練習と、確かめるテスト

1手ドリルは最初の 1 手だけを続けて出題。実力テストは 10・25・50 ハンドを打ち切って正答率を出します。

ドリルは手の種類とアップカードを選べます。テストの結果はハード・ソフト・ペアごとの正答率で確認できます。

正解ナビ

迷ったときにすぐ確認

自分の札とディーラーのアップカードを選ぶだけで、その場面の最善手を教えてくれます。

卓のゲーム条件

ルールが変われば、最善手も変わる

実際に打つ卓に合わせて条件を変えると、判定とストラテジー表がその卓の最善に変わります。

  • ゲームの種類（通常のブラックジャック／フリーベットブラックジャック）
  • ブラックジャックの配当（3:2・6:5）
  • ディーラーのソフト 17
  • デッキ数（1〜8）
  • ホールカードの有無
  • サレンダー
  • ダブルダウンの条件
  • スプリット後のダブル
  • スプリットの上限

安心して使うために

登録不要、すぐに遊べます

BJ Trainer は、登録なしで使えて、遊んだ記録は端末の中に保存するアプリです。お金のやり取りがあるのは Pro を買うときだけで、それも外部の決済サービス Stripe で行います。

登録は要りません

名前やメールアドレスの登録、ログインはありません。

遊んだ記録は端末の中だけ

設定、Lite の回数、言語などは、お使いの端末のブラウザの中にだけ保存します。遊んだ内容（手や成績）を運営者へ送ることはありません。アプリをよくするため、開いた回数と遊んだ時間だけを、個人を特定しない形で記録しています。

お支払いは決済サービス Stripe で

Pro の購入は、運営者とは別の会社である Stripe（ストライプ）の画面で行います。Stripe が運営する Link が販売者として代金を受け取り、税金の手続きもします。カード番号などの支払い情報は Stripe が扱い、運営者には届きません。

Stripe と Link について

Stripe は、世界中のオンライン販売に使われている決済サービスです。領収書は Link から届き、カードの明細には「LINK.COM*」で始まる名前で載ります。

Link のプライバシーポリシー

ページの下のお問い合わせフォームから送っていただいた内容（メールアドレスと本文）は、返信のために運営者に届きます。

はじめ方

ブラウザで開いて、ホーム画面に追加

App Store や Google Play からではなく、スマホのブラウザで使う Web アプリです。ホーム画面に追加すると、アプリのように全画面で使えます。

iPhone（Safari）

  1. 1ホーム画面の Safari を開く

  2. 2bj.sapiens-and-co.com を開き、右下の「…」をタップ

  3. 3「共有」をタップ

  4. 4「表示を増やす」（∨）をタップし、出てきた「ホーム画面に追加」をタップ

  5. 5「Web アプリとして開く」がオンのまま、「追加」をタップ

  6. 6ホーム画面に BJ Trainer が追加されます。ここから開きます

iPhone（iOS 26）の Safari の画面です。iOS の版によって、メニューの並びが少し違うことがあります。

Android（Chrome）

  1. 1ホーム画面の Chrome で開く

  2. 2bj.sapiens-and-co.com を開き、右上の「︙」をタップ

  3. 3「ホーム画面に追加」をタップ

  4. 4「インストール」をタップ

  5. 5「ホーム画面に追加」をタップ

  6. 6ホーム画面に BJ Trainer が追加されます。ここから開きます

Android 16 の Chrome の画面です。機種や Chrome の版によって、表示が少し違うことがあります。

一度開けば、通信が無くてもほとんどの機能が動きます。

よくある質問

FAQ

本物のお金は使いますか？
使いません。アプリの中で使うのは遊び用のお金だけで、本物のお金を賭けること、景品、換金はありません。
App Store や Google Play にありますか？
ありません。BJ Trainer は、スマホのブラウザで動く Web アプリとしてお届けしています。ホーム画面に追加すれば、アプリと同じように使えます。ストアへの登録は、皆さまの反応を見ながら考えていきますが、今のところ予定はありません。なお、将来ストア版を公開した場合も、Pro は購入のときのメールアドレスで引き継げるようにする予定です。買い直していただく必要はありません。
機種を替えたら Pro はどうなりますか？
新しい端末で BJ Trainer を開き、設定の「購入を復元」に、購入のときに入力したメールアドレス（Link から届いた領収書の宛先）を入れると Pro に戻せます。
通信は必要ですか？
最初の 1 回だけ必要です。一度開けば、通信が無くてもほとんどの機能が動きます。
基本戦略を覚えれば勝てますか？
勝ちを保証するものではありません。基本戦略は、ハウスエッジ（ディーラー側に有利な差）を小さくするための打ち方です。
